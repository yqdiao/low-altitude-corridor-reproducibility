# 来源与核验记录

## 来源范围

- 来源：用户提供的 Overleaf 项目 *When Does Congestion Justify Access Charges? Pricing, Auctions, and Capacity Release in Low-Altitude Logistics Corridors*，2026-09-30 读取。
- 已阅读 `sections/paper_body.tex`、`sections/paper_appendix.tex` 与 `sections/managerial_conclusion.tex` 的相关内容。
- 源项目中观察到的图形为 `fig1_revenue_ranking.pdf` 至 `fig8_regime_maps.pdf`，没有观察到 Python / R / MATLAB 绘图源程序。
- 参数直接来自论文 Table 2（LaTeX 标签 `tab:calibration`）、正文图形说明，以及原图坐标轴。模型方程的稳定标签列于逐图说明和代码注释。
- 仓库中的 Python 代码是独立重建实现。网格点数、文件组织、300 dpi PNG 输出、CSV 格式及图形排版是本次复现的实现选择，并非声称从原程序恢复。

## 原图存档

`reference_figures/` 的 PDF 由编译后的论文 PDF 中八个 Form XObject 提取，保留矢量曲线、字体与图中文字。它们不是屏幕截图，也不依赖曲线图片来生成复现数据。独立 PDF 外壳与原来 Overleaf 单图文件的字节可能不同。

`reference_figures/manifest.json` 记录编译 PDF 的 SHA-256、对应页码和每张提取图的 SHA-256。原始完整论文及 Overleaf 的编辑访问链接不放入公开仓库。`scripts/extract_reference_figures.py` 可对同一结构的编译 PDF 重做提取。

## 自动核验

### 数学与数值检查：10 项全部通过

1. 福利分解表中 α=1、1.5、2、3 的 Model A/MUPA 关键数值，与论文三位小数一致。
2. Model A 内点和退出解与独立有约束数值优化器一致。
3. MUPA 分配与对手报价下的单边数量偏离最优化一致，且满足福利会计恒等式。
4. VCG 分段收入与直接计算外部性支付一致，切换点连续。
5. 图 4 的协调阈值端点、约束运营商与一次博弈测试符合论文。
6. 图 5 的 R=4 交点及全区间的协调可持续性检查通过。
7. Model D 释放正根与直接目标函数优化一致，并检查 γ=0 极限及 KKT 条件。
8. 图 7 的投资数值、包络残差和两项边际收益分解符合论文。
9. Model D 的一维包络解与直接联合优化 `(K,N_L,N_H)` 一致。
10. 零价格一次博弈的解析偏离最大值与稠密数量网格计算一致。

运行：`python -m unittest discover -s tests -v`。代表数值见 `numerical_validation.json`。

### 与原图独立核对

`audit_reference_curves.py` 从原图 PDF 中直接读取绘图路径顶点，依据原图刻度线坐标做线性坐标变换，然后在相同横坐标下计算重建公式。

图 1、3、4、5、6 共 12 段原始曲线路径通过检查，最大绝对偏差约 3.7×10⁻⁶（包括 PDF 坐标存储和变换误差）。参见 `reference_curve_audit.json`。这不是将新图与自身代码做比较，也不是基于肉眼相似度的判断。

图 2、7、8 的验证使用数值模型测试、文中的边界/代表值和视觉检查；未声称对这些多面板图执行逐顶点比对。所有新图均已生成并视觉检查。

### 可复现性的范围

在固定依赖、字体、平台下，输入、CSV 数据与算法确定。PDF 已移除创建/修改时间戳。不同操作系统的字体渲染或依赖底层库可能使图片/PDF 哈希不同；应首先比较 CSV 与数学验证结果，不以跨平台文件字节完全一致作为经济模型复现标准。

## 原图的外推和假设边界

1. 图 1 的非策略曲线在 N<1 延用内点收入公式，而真实分配已经进入单运营商角点。为忠实对应原图，绘图保留该曲线；CSV 同时提供正确分段值。MUPA 在 N≤.5 的点线也不属于双运营商正价格均衡。
2. 图 2(b) 在 N≤2.5 的点线仅为供给候选公式，不是外部区域已求解的均衡。
3. 图 8(b) 在 t̄=4 时将 Δ 扫描到 10。由 t₁=4−Δ/2，Δ≥8 不满足 t₁>0。数据保留该原图范围，并增加 `primitive_cost_valid` 标记。区域分类是按原图公式进行的代数检验，不消除该原始成本假设限制。
4. 图 8(a) 的斜率阈值比较仍需相应模型的内点条件；原图 y=κ/b=0 是显示边界，不能解释为 κ>0 条件已满足。
5. 图 5 的储备价容量比较有额外实施假设。图 8 的一次博弈构造失败并不排除其他形式的零价格均衡。

这些说明不会修改原论文；它们使复现资料中公式、原图和经济含义的边界可查。
